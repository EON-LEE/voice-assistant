Prepare useful material

Supported: PPTX, DOCX, text-based PDF, Markdown, UTF-8 notes and common code files. Files must be at most 5 MiB each. The service reports document and chunk quotas above.

Text only: text inside images, screenshots, charts and diagrams is not read. Scanned PDFs need text recognition first. Slide text and notes can be extracted from PPTX, but images/diagram text inside slides are NOT read. Legacy .doc and .ppt are unsupported; save as DOCX/PPTX or a text-based PDF.

  • Use one topic per file and put that topic in the title.
  • Add a glossary of names and terms, and a short Q&A document.
  • Write key decisions, facts and explanations as text, not only in screenshots.
  • Hidden/build folders, binaries and unsupported file types are skipped with counts before upload.

Indexing does not guarantee that a document supports every answer. Verify references before relying on a suggested reply. No microphone or screen capture runs on this page.
