# Kestrova Pulse product overview

Kestrova Analytics makes Kestrova Pulse, a cloud service that watches factory sensor data and flags unusual machine behavior early.

- Kestrova Pulse 3.0 became generally available on 14 January 2026.
- Pulse reads sensor data through the Orrin edge gateway. The current gateway model is the ORN-4, installed next to the machines.
- The TALLIS module (Threshold-Aware Live Line Inspection Service) sends an alert when a production line drifts out of its normal range.
- Pulse connects to machines over OPC UA, MQTT and Modbus TCP.
- A typical pilot connects 40 to 120 sensors and runs for 6 weeks.
- Pulse keeps sensor history for 400 days by default.
